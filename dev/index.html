CrabCap · dev preview

เปิดหน้า UI ของ extension ในแท็บธรรมดาได้โดยไม่ต้องติดตั้ง ใช้ chrome.* จำลองจาก lib/boot.js และเก็บภาพใน IndexedDB ของ origin นี้ (แยกจาก extension จริง)

หน้านี้กำลังรันอยู่ใน extension จริง ภาพตัวอย่างจะถูกเพิ่มเข้าไปในประวัติจริงด้วย

1. สร้างภาพตัวอย่าง

สร้างภาพจำลอง 4 แบบ (ทั้งหน้ายาว, ส่วนที่มองเห็น, เลือกพื้นที่, element) แล้วบันทึกลงฐานข้อมูล

2. เปิดหน้า UI

Popup ภาพทั้งหมด ภาพล่าสุด (result) result: ไม่พบภาพ

3. การ์ดความคืบหน้าในหน้าเว็บ

จำลองสิ่งที่ผู้ใช้เห็นระหว่างแคปทั้งหน้า กด Esc หรือ "ยกเลิก" ได้
